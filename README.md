# Harrow–Hassidim–Lloyd algorithm

The goal of this repo is to implement the Harrow–Hassidim–Lloyd algorithm to solve linear systems.

## Installation
To install the dependencies create and activate a new python environment by 
```{bash}
python -m venv .venv
source .venv/bin/activate
```
and run the following
```{bash}
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

To execute code on real quantum hardware you will need an IBM API key. To do that you will need to register to this [link](https://quantum.cloud.ibm.com/signin) and generate an API key.
